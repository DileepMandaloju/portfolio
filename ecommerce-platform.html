E-Commerce Storefront & Admin Panel

Academic project · PHP · MySQL · JavaScript
Software Development

Overview

A customer-facing storefront with cart and checkout, backed by a separate admin panel for managing products and order fulfillment - built to understand how a transaction stays consistent from cart to completed order.

Key Contributions

  • Built the storefront: product listing, add-to-cart, quantity updates, and item removal.
  • Implemented checkout as a database transaction - order, order items, and cart clearing all commit together, with rollback on any failure.
  • Stored the purchase-time price on each order line item, so later price changes never affect historical orders.
  • Built a separate, auth-gated admin panel for product CRUD and order status management (pending / completed / cancelled).
  • Used mysqli prepared statements throughout to prevent SQL injection across storefront and admin queries.
