College Placement Portal

Academic project · PHP · MySQL (PDO) · Bootstrap 5
Software Development

Overview

A role-based web portal connecting students, companies, and college administrators around campus placements — students browse and apply to jobs, companies post openings and review applicants, and admins get a platform-wide analytics view.

Key Contributions

  • Designed a three-role architecture (student, company, admin), each with its own authentication flow and dashboard.
  • Built the student flow for browsing open jobs and applying, with duplicate-application checks before insert.
  • Built the company flow for posting jobs and reviewing applicants, with status badges (pending / shortlisted / rejected).
  • Built an admin dashboard aggregating platform-wide totals (students, companies, jobs, applications) and a recent-activity feed.
  • Used PDO prepared statements throughout and password_hash/password_verify for credential security.
  • Modeled the relational schema with foreign keys and cascading deletes across students, companies, jobs, and applications.
