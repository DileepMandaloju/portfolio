AI-Powered Job Portal

Feb 2026 · Python · Flask · SQLite · Google Gemini API
Software Development

Overview

A recruiter-facing applicant tracking system built with Flask. Recruiters post job listings, candidates apply with a PDF resume, and recruiters can trigger an on-demand AI analysis that reads each resume and scores how well it fits the specific job description.

Key Contributions

  • Built the full recruiter workflow - registration, login, job posting, and a dashboard listing applicant counts per job.
  • Integrated Google's Gemini 2.5 Flash model to read extracted resume text against a job description and return a structured "fit score" (0-100) with a two-sentence summary.
  • Used PyPDF2 to extract text from uploaded PDF resumes, with Werkzeug's secure_filename to keep uploads safe.
  • Enforced strict JSON-only responses from the AI with response sanitization, so a single malformed reply can't break the recruiter dashboard.
  • Designed the SQLite schema (users, jobs, applications) with the AI summary and score stored per application, ranked automatically for recruiters.
  • Applied secure password hashing via Werkzeug and session-based authentication throughout.
