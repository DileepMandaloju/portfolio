Heart Disease Prediction System

Academic project · Python · scikit-learn · Logistic Regression
Data & Analytics

Overview

A machine learning system that estimates the likelihood of heart disease from patient health parameters — age, cholesterol, blood pressure, and heart rate — served through a simple web interface for real-time predictions.

Key Contributions

  • Performed data preprocessing and feature selection on a healthcare dataset to prepare it for modeling.
  • Trained a logistic regression model for binary classification of heart disease risk.
  • Built a lightweight web interface so predictions can be generated from patient inputs in real time.
  • Prioritized interpretability alongside accuracy, keeping the model's reasoning legible for a healthcare context.
