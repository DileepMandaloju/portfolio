Retail Sales Data Warehouse & BI Pipeline

Apr 2025 · Python · PySpark · PostgreSQL · Tableau
Data & Analytics

Overview

A distributed ELT pipeline that ingests and processes over 1,000,000 retail transactions, transforming them into an optimized data warehouse and surfacing the results through interactive Tableau dashboards.

Key Contributions

  • Engineered a distributed PySpark ELT pipeline to ingest and process 1,000,000+ retail transactions, enabling scalable data throughput.
  • Architected a Kimball star schema in PostgreSQL, transforming flat staging data into optimized fact and dimension tables for reporting.
  • Resolved data anomalies using advanced SQL window functions to deduplicate records, achieving 100% referential integrity.
  • Automated data extraction with Python (psycopg2) to feed interactive Tableau dashboards tracking year-over-year revenue and geographic sales trends.
