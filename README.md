# Dileep Mandaloju — Portfolio

This repository contains the source code for my personal portfolio website.

The purpose of this project is to create a simple and professional online presence to
showcase my background, skills, and projects as a Computer Science (Data Science)
student. It serves as a central place for recruiters, collaborators, and other
developers to learn about my work.

The portfolio highlights my technical skills, academic background, certifications, and
practical projects spanning data analytics, data engineering, and full-stack web
development. It is designed to be clean, easy to navigate, and continuously updated as
I learn and build more.

## Projects featured

- AI-Powered Job Portal — Flask ATS with Google Gemini-powered resume-to-job fit scoring
- Retail Sales Data Warehouse & BI Pipeline — PySpark ELT pipeline into a PostgreSQL star schema, visualized in Tableau
- Student & Teacher Performance Dashboard — Power BI dashboard for academic KPI tracking
- Heart Disease Prediction System — Logistic regression risk model with a simple web interface
- College Placement Portal — Role-based PHP/MySQL portal for students, companies, and admins
- E-Commerce Storefront & Admin Panel — PHP/MySQL storefront with transactional checkout
- Personal Expense Tracker — Flask app with a REST API and Plotly analytics

## Tech stack

HTML, CSS, JavaScript for the site itself; project write-ups cover Python, SQL, Power BI,
Tableau, Flask, PHP, and PostgreSQL/MySQL/SQLite depending on the project.
