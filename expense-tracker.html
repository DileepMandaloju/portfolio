Personal Expense Tracker

Academic project · Python · Flask · SQLAlchemy · Plotly
Software Development

Overview

A Flask web app for tracking personal spending, with both a standard web UI and a REST API, plus an analytics view that breaks spending down by category and by day over a chosen date range.

Key Contributions

  • Built full CRUD for expenses (amount, category, note, date) with Flask-Login-gated access per user.
  • Exposed the same functionality as a REST API (GET/POST/PUT/DELETE on /api/expenses) alongside the web UI.
  • Built an analytics route with date-range filtering, aggregating totals with SQLAlchemy's func.sum grouped by category and by date.
  • Rendered the results as interactive Plotly charts — a category breakdown pie chart and a daily spending bar chart — plus KPI cards for total spend, top category, and daily average.
  • Hashed passwords with Werkzeug and used Flask-Login for session management.
